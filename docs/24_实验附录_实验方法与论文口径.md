# 24. 实验附录：实验方法与论文口径

## 1. 实验闭环
- 固定流程：`代码策略改造 -> canonical+dev 单seed -> 样本级归因 -> 快照追加 -> commit -> 周期性多seed复核`。
- 稳定达标优先，不以单轮峰值作为停止标准。

## 2. 评测门禁
### 单seed（seed=42）
- canonical：`overall F1 >= 0.37`，`single_doc_qa F1 >= 0.29`，`P95 ratio <= 1.8`，`oom_count=0`。
- dev100：`overall F1 >= 0.28`，`single_doc_qa F1 >= 0.24`，`P95 ratio <= 2.30`，`oom_count=0`。

### 多seed（42/123/2026）
- canonical：`mean F1 >= 0.37`，`mean single_doc >= 0.29`，`mean ratio <= 1.8`，各 seed `oom=0`。
- holdout100：`mean F1 >= 0.35`，`mean single_doc >= 0.27`，`mean ratio <= 1.9`，各 seed `oom=0`。

## 3. 关键策略说明（实验内容层）
- `single_doc_answer_type`：`count / paragraph_id / entity_short / open_text`。
- fastpath：对 `count/paragraph_id/entity_short` 限制为 `max_steps<=2`，并禁 refine。
- forced-retrieve：fastpath 下仅在首轮 final 且 evidence overlap 低于阈值时触发。
- fallback 抽取：`best_answer_from_chunks` 改为 task-aware 抽取，减少长文本输出对 char-F1 的稀释。
- auto policy：纳入 dev 轨道门禁，延迟劣化时优先收紧 single_doc 的 refine/forced-retrieve。

## 4. 论文表格口径
### 主结果表
- canonical 3-seed：报告 `mean/std`（必要时补 95% CI）。

### 泛化表
- holdout100 3-seed：同口径报告 `mean/std`。

### 稳定性表
- 报告 `P95 ratio` 分布、Top 延迟样本、`avg_steps/avg_retrieval`。

### 消融表（建议）
- 去掉 fastpath。
- 去掉 refine_gate。
- 去掉 task-aware fallback 抽取。

## 5. 风险与解释模板
- 若 overall 与 single_doc 未同时过线：强调“主要瓶颈在 single_doc 稳定性，不是 key tasks 召回不足”。
- 若 dev ratio 高于阈值：强调“额外检索与 refine 触发链造成尾延迟抬升”。
- 若多seed波动大：强调“策略触发边界敏感，需进一步收敛决策门禁”。
