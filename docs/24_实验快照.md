## 4) 每轮快照

### Round 0（锚定轮）
- 运行：
  - `run_baseline_rag.py` -> `results/baseline_rag_formal_anchor_20260217_154511.jsonl`
  - `evaluate.py` -> `report/formal_anchor_20260217_154511/`
- 作用：固定 baseline 对照，避免每轮波动影响判断。

### Round 1（single_doc 恢复尝试）
- 改动：
  - `agent.early_stop.single_doc_max_steps: 2 -> 3`
  - `agent.early_stop.max_same_keyword_hits: 2 -> 3`
  - `single_doc_qa` task-aware `top_k_init >= 3`
- 结果：
  - F1 0.3334，P95 54.94s，single_doc 0.2331，OOM=1
- 结论：延迟可控，但质量下降；进入协议鲁棒性修复。

### Round 2（协议鲁棒性）
- 改动：
  - `format_repair.max_retries: 1 -> 2`
  - repair 流程改为可重试循环，失败保留审计字段并回退 `best_answer_from_chunks`
- 结果：
  - F1 0.3642（过线），single_doc 0.2706（接近目标），但 P95 85.61s（超线）
- 结论：质量恢复，但长尾严重。

### Round 3（query rewrite 重检索）
- 改动：
  - 在 `same_keyword/no_new_chunk` 触发前允许一次 rewrite 重检索（仅一次）
- 结果：
  - F1 0.3613（过线），P95 101.58s（明显恶化），single_doc 0.2114
- 结论：rewrite 增益不足且尾延迟放大，后续默认关闭。

### Round 4（single_doc 激进增配）
- 改动：
  - `single_doc top_k_init -> 5`
  - `single_doc max_new_tokens -> 384`
- 结果：
  - F1 0.2980，single_doc 0.2361，P95 ratio 1.8436（仍超）
- 结论：激进增配无效，回撤。

### Round 5（回拉延迟）
- 改动：
  - `max_steps: 3`，`max_new_tokens: 256`
  - rewrite 配置化并关闭
- 结果：
  - F1 0.3328，P95 71.32s（接近线），single_doc 0.2449
- 结论：延迟改善但质量不足。

### Round 6（no_new 强早停）
- 改动：
  - `max_no_new_chunk_steps: 2 -> 1`
  - `single_doc top_k_init: 4`
- 结果：
  - P95 51.38s（过线），但 F1 0.2617、single_doc 0.1974
  - trace 显示 `forced_final` 6 次，全部由 `no_new_chunk_steps>=1`
- 结论：过早终止导致质量明显坍缩，回撤。

### Round 7（温和回调）
- 改动：
  - `max_no_new_chunk_steps` 回到 2
  - 关闭 single_doc shortcut
  - `max_new_tokens: 288`
- 结果：
  - F1 0.2875，single_doc 0.1787，P95 ratio 1.8658
- 结论：仍不稳定。

### Round 8（最终轮，最佳）
- 改动：
  - `max_steps: 3`
  - single_doc shortcut 恢复开启
  - `single_doc top_k_init: 3`
  - 增加 single_doc 低置信回退精修（仅在 `forced_final` / `format_repair_failed` / `短回答` 场景触发）
- 结果：
  - F1 `0.3781`（过线）
  - P95 `65.48s`，ratio `1.6898`（过线）
  - single_doc `0.2812`（未达 0.29）
  - OOM `0`（过线）
  - trace（`results/run_20260217_100728/trace`）：`forced_final=3`，`rewrite=0`，`repair_failed=0`
- 结论：在护栏内达到当前最佳，但 single_doc 仍差 `0.0088`。

## 5) 当前最佳结论（护栏触发后的阶段性收敛）
- 最佳轮次：`Round 8`
- 达标情况：4 项中 3 项通过，仅 `single_doc_qa F1 >= 0.29` 未通过
- 与 anchor baseline 对比（R8）：

  - P95：`38.75s -> 65.48s`（ratio 1.6898）
