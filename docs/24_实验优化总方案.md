# 24. 实验优化总方案（Canonical 三任务平衡版）

## 1. 目标口径
- 主目标：`single_doc_qa + multi_doc_qa + code_qa` 三任务平衡，不再以 dev/holdout 指标主导调参。
- 主实验门槛（canonical, seed=42）：
  - `overall F1 >= 0.37`
  - `single_doc_qa F1 >= 0.29`
  - `P95(agent)/P95(baseline) <= 1.8`
  - `oom_count = 0`
- 稳定门槛（canonical, seeds=42/123/2026）：
  - `mean overall F1 >= 0.37`
  - `mean single_doc_qa F1 >= 0.29`
  - `mean P95 ratio <= 1.8`
  - `all seeds oom_count = 0`
- 显著性门槛：三任务 `agent-baseline` 的 seed-level delta F1，至少 `2/3` 任务 `95%CI` 下界 `> 0`。

## 2. 实验结构
- Main Track（主实验）：canonical 数据集，baseline vs edge_agent，单 seed 迭代 + 周期性 3-seed。
- Extended Track（扩展实验）：dev100 + holdout100，仅用于泛化验证，不反向主导主实验调参。
- Ablation Track（机制消融）：固定 `iterative_off`、`fastpath_off`、`refine_gate_relaxed`。

## 3. 自动迭代策略
- 评分函数：canonical 主导，dev 仅作弱惩罚项。
- 策略顺序：先修 canonical 失败维度（ratio/single_doc/overall/oom），再执行 dev guard。
- 多 seed 触发：连续 2 轮 canonical 单 seed 通过，或每 3 轮强制一次。
- 停止规则：连续 2 次 canonical 3-seed 通过。
- 回归保护：任一任务相对最佳稳定轮下降 `>0.03` 时自动回滚 `results/last_good_config.yaml`。

## 4. 配置冻结（r23_lock 起点）
- `configs/agent.yaml` 作为统一起点，关键约束：
  - `single_doc.answer_type_policy.enable=false`
  - `single_doc.refine_gate.on_forced_final=true`
  - `single_doc.forced_retrieve.force_on_first_final=false`
  - `answer_postprocess.single_doc_compact=false`

## 5. 输出与审计
- 轮次状态：`results/auto_iterate_state.json`
- 最佳回滚锚点：`results/last_good_config.yaml`
- 每轮快照：`docs/24_实验快照_当前.md`（只追加）
- 历史快照：`docs/24_实验快照_历史.md`（只追加）

## 6. 兼容性
- 不改公共 CLI。
- 不改评测 schema；仅追加审计字段并保持向后兼容。
