# 01 Storyline

## 一句话版本

在 `Qwen3 4B` 这一级别的小模型上，长文档失败模式具有明显任务异质性。相比统一的单轮 RAG，预算感知的任务路由式 agent 协议可以显著提升 `overall`、`multi_doc_qa` 和尤其是 `code_qa`，但同时暴露了 `single_doc_qa` 的特定代价与失效边界。

## 推荐论文主张

不要写成：

- “4B 小模型在三任务上全面平衡提升”
- “通用端侧 agent 全面超过基线”
- “我们的方法证明 4B 可以替代更大模型”

推荐写成：

- “预算受限长文档场景下，4B 小模型需要任务感知协议，而不是统一流程”
- “任务路由式 protocol 在 canonical 上带来显著 `overall` 与 `code_qa` 收益”
- “方法的价值不仅在平均分提升，也在揭示任务异质性和失败模式”

## 当前最稳的故事结构

### 会议稿

标题级亮点：

- `code_qa` 是标题级亮点
- 但正式主证据仍来自 `canonical` 主表和任务分解

推荐问题定义：

1. 4B 小模型在长文档三任务中是否存在任务异质性？
2. 统一 RAG 是否会同时牺牲代码理解与跨文档聚合？
3. budget-aware task-routed protocol 是否能在不扩大模型规模的前提下获得更优 `overall` 与关键任务收益？

### 毕业稿

毕业稿不需要更换主张，只需要扩展：

- 系统设计与工程实现
- 数据体系和正式流程
- 运行监控、故障恢复和结果口径治理
- 失败样例和局限性讨论

## 当前可直接写的研究问题

### RQ1

在 `LongBench_3tasks canonical` 上，`edge_agent_4b` 相比 `baseline_rag_4b` 是否能获得更高的正式主结果？

当前已验证答案：

- 能
- `overall F1` 从 `0.2552` 提升到 `0.3351`

### RQ2

收益主要来自哪些任务？

当前已验证答案：

- `code_qa`：强正收益，`+0.2079`
- `multi_doc_qa`：中等正收益，`+0.0288`
- `single_doc_qa`：负收益，`-0.0363`

### RQ3

这种收益是否伴随额外成本和风险？

当前已验证答案：

- 是
- `p95 latency` 比例约 `1.333`
- `OOM` 从 `0` 增至 `3`
- 风险主要集中在 `single_doc_qa`

## 推荐贡献写法

### 贡献 1

提出一种适配 `Qwen3 4B` 长文档推理的 `budget-aware task-routed protocol`，核心不是让小模型“变大”，而是在有限预算下按任务类型分配检索、记忆和迭代策略。

### 贡献 2

在 `LongBench_3tasks canonical` 上，相比标准 RAG 基线，方法带来显著 `overall` 提升，并在 `code_qa` 上显示出大幅收益。

### 贡献 3

本文同时报告方法的边界条件：尽管 `multi_doc_qa` 和 `code_qa` 获益明显，但 `single_doc_qa` 仍存在性能回撤，说明统一 agent 协议在不同长文档任务上的最优策略并不一致。

## 推荐题目方向

可接受的题目风格：

- 小模型 + 长文档 + 预算约束 + 任务路由
- `code_qa` 亮点 + `canonical` 主证据
- “收益与边界并报”

不建议的题目风格：

- “通用智能体”
- “全面提升”
- “替代大模型”
